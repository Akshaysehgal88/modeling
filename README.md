# Modeling

Company-level financial modeling and scenario analysis.

## Scenario Lab

[Scenario Lab](scenario-lab/README.md) is an equity simulation tool for a curated
set of 20 semiconductor and AI infrastructure companies. Select a company,
review its demo assumptions, and explore earnings forecasts, business events,
and monthly market conditions through a shared interface.

Each preset uses company-specific inputs and listing units. Features include
interactive charts, native currencies, optional currency conversion, saved
scenarios, and downloadable results.
